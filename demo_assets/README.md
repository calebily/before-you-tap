# Fictional Demo Assets

Every name, address, account detail, amount, phone number, and scenario in this folder is fictional.
The `.example` domain is reserved for documentation and cannot be a real service.

## Recommended demo sequence

1. Upload `high-risk-bank-page-1.png` and `high-risk-bank-page-2.png` together, in that order.
2. Show the High risk result and select **I clicked the link**.
3. Record `be-careful-delivery-voicemail.txt` in Voice Memos, export it as M4A, and use it for the
   short audio demonstration.
4. Keep `low-concern-appointment-reminder.png` as a backup or closing montage result.

Risk classification is model-generated and is not guaranteed solely by the filename. Run every
asset through the deployed version immediately before recording. If a result differs, do not rename
or misrepresent it; adjust the narration or use another pre-tested fictional asset.

## Recording Voice Memo files

- Read naturally and do not add background music.
- Leave roughly half a second of silence at the start and end.
- Keep each recording under 15 seconds.
- Export from Voice Memos using Share, then save to Files or AirDrop to the Mac.
- Use filenames that do not contain a real name or phone number.
