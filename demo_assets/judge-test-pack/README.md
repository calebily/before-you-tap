# Before You Tap — Judge Test Pack

These fictional assets provide a quick, reproducible way to test Before You Tap without using personal or sensitive content.

## Included files

| File | Test case | Intended result |
| --- | --- | --- |
| `high-risk-bank-page-1.png` | Page 1 of a fictional bank message | Upload with page 2; designed to produce **High risk** |
| `high-risk-bank-page-2.png` | Page 2 of the same fictional bank message | Upload after page 1 |
| `high-risk-bank-voicemail.mp3` | Fictional urgent bank-security voicemail | Designed to produce **High risk** |
| `low-concern-clinic-voicemail.mp3` | Fictional routine appointment reminder | Designed to produce **Low concern** |

## Quick test

1. Open the [hosted app](https://before-you-tap-484523463568.australia-southeast1.run.app).
2. Select **Photo or screenshot**.
3. Upload both bank-message images together, with page 1 before page 2, and select **Check these images**.
4. After the result appears, choose **I clicked the link** to test the adaptive follow-up guidance.
5. Return to the home screen, select **Check an audio message**, and upload either MP3 file. Test the recordings one at a time.

Model output can vary. Before You Tap provides decision support rather than a guarantee that a message is safe or fraudulent.

## Safety and provenance

- Every organization, message, scenario, and web address in this folder is fictional.
- The `.example` domain is used intentionally and does not lead to a real bank website.
- The audio files were generated with an ElevenLabs stock voice for hackathon testing.
- The assets contain no real account details, passwords, verification codes, phone numbers, or personal information.
- These files are for product evaluation and scam-awareness testing only. They must not be used to contact or mislead anyone.
